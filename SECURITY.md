# Security Policy

- Never commit passwords, API keys, private keys, face images, embeddings, recordings, or VPN credentials.
- Keep the dashboard on a trusted LAN/VPN interface.
- Do not expose the camera or admin API directly to the public Internet.
- Run the Orange Pi application as a dedicated unprivileged service account.
- Store secrets outside Git.
- Use strong authentication for administrative actions.
- Apply OS security updates when Internet access is available.
- Configure media retention so old recordings are automatically removed.

For security issues, use a private GitHub security report when available. Do not publish credentials or sensitive recordings in an issue.
