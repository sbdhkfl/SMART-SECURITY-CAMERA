# 01 - Architecture\n\n## The simple version\n\nESP32-S3-CAM sees the room and provides the camera stream. The Orange Pi receives it and performs the local AI, storage, audio, API, and dashboard work.\n\n## Event flow\n\n1. Camera sends a frame.\n2. Orange Pi detects a face.\n3. A matching enrolled face is marked known.\n4. A non-matching face creates an unknown-person event.\n5. A snapshot is saved.\n6. Optional video recording starts or continues according to configuration.\n7. A local voice prompt can ask the person to identify themselves.\n8. USB microphone recording captures the response.\n9. Optional local speech-to-text creates a transcript.\n10. The dashboard shows the event.\n\n## Offline mode\n\nCamera, AI models, database, storage, microphone, and dashboard are designed to operate on the local network without cloud services.\n\n## Remote mode\n\nRemote access is a separate network layer. A VPN such as WireGuard can provide a private path into the home network. The camera application should not be opened directly to the Internet.\n\n## Planned software layers\n\n- ESP32 firmware\n- camera client\n- AI pipeline\n- face enrollment and recognition\n- event manager\n- audio manager\n- SQLite database\n- media retention manager\n- FastAPI web/API service\n- browser dashboard\n- systemd service\n- health checks\n- automated tests\n
